# Эмулятор командной строки UNIX-подобной ОС (Вариант №25)

## 1. Общее описание
Проект представляет собой эмулятор командной строки 
UNIX-подобной ОС для практических работ по дисциплине 
«Конфигурационное управление». На текущем этапе 
реализованы настраиваемая конфигурация CLI, загрузка 
виртуальной файловой системы (VFS) из JSON в память, 
а также полноценная логика основных команд.

## 2. Описание функций и настроек
- **Архитектура:** код использует docstring вместо 
  строковых комментариев.
- **Основные функции:** 
  * `parse_and_expand(user_input)` — парсинг и 
    раскрытие переменных окружения реальной ОС.
  * `load_vfs(vfs_path)` — чтение JSON-структуры 
    файловой системы в оперативную память.
  * `run_script(script_path, prompt)` — исполнение 
    стартовых сценариев команд с пропуском ошибок.
- **Команды:** `exit` (выход), `ls` (вывод папки), 
  `cd` (смена каталога), `uniq` (удаление дубликатов 
  строк), `wc` (подсчет строк/слов/байт), `who` 
  (текущий пользователь).

## 3. Сборка и запуск
- **Требования:** Python 3.8+, только стандартные 
  модули (`os`, `sys`, `getpass`, `socket`, `json`, 
  `argparse`).
- **Запуск:** 
  ```bash
  python3 src/emulator.py --vfs vfs.json
  # или со стартовым скриптом
  python3 src/emulator.py --vfs vfs.json --script start.txt
  ```
- **Тесты:** `python3 -m unittest discover -s tests`

## 4. Примеры использования
Примеры выполнения цепочки команд в эмуляторе:
```text
talgat@MacBook-Pro:~\$ who
talgat
talgat@MacBook-Pro:~\$ ls
etc  home
talgat@MacBook-Pro:~\$ cd home
talgat@MacBook-Pro:~\$ uniq test.txt
aaa
bbb
```

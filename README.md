# Эмулятор командной строки UNIX-подобной ОС (Вариант №25)

## 1. Общее описание
Проект представляет собой эмулятор командной строки UNIX-подобной ОС для практических работ по дисциплине «Конфигурационное управление». На Этапе 1 (REPL) реализованы CLI с динамическим приглашением, парсер с раскрытием переменных окружения, команды-заглушки и обработка ошибок.

## 2. Описание функций и настроек
- **Архитектура:** код использует docstring вместо строковых комментариев. Основные функции: `parse_and_expand(user_input)` (парсинг и раскрытие переменных через `os.environ`) и `run_repl()` (главный цикл REPL).
- **Команды:** `exit` (завершение), `ls` (заглушка вывода каталога), `cd` (заглушка смены директории).

## 3. Сборка и запуск
- **Требования:** Python 3.8+, только стандартные модули (`os`, `sys`, `getpass`, `socket`).
- **Запуск:** 
  ```bash
  chmod +x run.sh && ./run.sh
  # или
  python3 src/emulator.py
  ```
- **Тесты:** `python3 -m unittest discover -s tests`

## 4. Примеры использования
Примеры работы с подстановкой переменных (`$USER`), выводом ошибок валидации (`cd: too many arguments`, `command not found`) и завершением сессии через `exit` или сигналы `Ctrl+C` / `Ctrl+D`.

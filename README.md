# Эмулятор командной строки UNIX-подобной ОС (Вариант №25)

## 1. Общее описание
Данный проект представляет собой эмулятор командной строки, имитирующий интерфейс и базовое поведение терминала UNIX-подобных операционных систем. Программа разработана в рамках выполнения практических работ по дисциплине «Конфигурационное управление».

На текущем Этапе 1 (REPL) реализован минимальный рабочий прототип:
* Консольный интерфейс пользователя (CLI) с динамическим формированием строки приглашения.
* Парсер входной строки с поддержкой раскрытия системных переменных окружения.
* Команды-заглушки для навигации и просмотра структуры.
* Обработка синтаксических ошибок (неизвестные команды, избыточные аргументы) и корректное завершение сессии.

---

## 2. Описание функций и настроек

### Архитектура программного кода
В соответствии с требованиями к оформлению, код не содержит стандартных комментариев строк (`#`). Все описания алгоритмов вынесены в документационные строки функций (**docstring**):

* **`parse_and_expand(user_input)`** — разбивает входную строку по пробелам на имя команды и список аргументов. Выполняет итерацию по полученным аргументам: если элемент начинается с символа `$`, функция извлекает соответствующее значение переменной окружения из операционной системы с помощью `os.environ`.
* **`run_repl()`** — запускает главный цикл эмулятора. Автоматически считывает имя пользователя и сетевое имя хоста для формирования приглашения к вводу. Передает введенные строки в парсер, проверяет корректность вызова встроенных команд и перенаправляет сообщения об ошибках в поток `sys.stderr`.

### Список поддерживаемых команд
1. **`exit`** — завершение работы эмулятора. Команда не принимает дополнительных аргументов.
2. **`ls`** *(заглушка)* — имитация вывода содержимого каталога. Отображает факт вызова и переданные аргументы.
3. **`cd`** *(заглушка)* — имитация смены текущей директории. Принимает не более одного аргумента (путь).

## 3. Описание команд для сборки проекта и запуска тестов

### Системные требования
* Интерпретатор Python версии 3.8 или выше.
* Использование сторонних библиотек и зависимостей не требуется (применяются стандартные модули `os`, `sys`, `getpass`, `socket`).

### Команда запуска приложения
Программа запускается в интерактивном режиме напрямую через консоль:
```bash
python src/emulator.py
```

### Запуск автоматических тестов
Для проведения тестирования парсера и механизма раскрытия переменных выполните команду:
```bash
python -m unittest discover -s tests
```

## 4. Примеры использования

Ниже представлены примеры сессий работы эмулятора, демонстрирующие обработку штатных ситуаций, раскрытие переменных окружения и реакцию на ошибочные действия пользователя.

### Корректное выполнение команд и подстановка переменных
```bash
student@computer:~\$ ls -la /home/student
[заглушка] Вызвана команда: ls
[заглушка] Переданные аргументы: ['-la', '/home/student']

student@computer:~\(cd\)USER
[заглушка] Вызвана команда: cd
[заглушка] Переданные аргументы: ['student']
```

### Обработка ошибок валидации и вызов неизвестных команд
```bash
student@computer:~\$ clear
bash: clear: command not found

student@computer:~\$ cd /var /log
cd: too many arguments

student@computer:~\$ exit now
exit: too many arguments
```

### Завершение работы
```bash
student@computer:~\$ exit
logout
```
*(Программа также корректно обрабатывает сигналы прерывания Ctrl+C и Ctrl+D, завершая сессию выводом сообщения `logout`).*

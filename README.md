# Эмулятор командной строки UNIX-подобной ОС

## 1. Общее описание
Проект представляет собой эмулятор командной строки
UNIX-подобной ОС для практических работ по дисциплине
«Конфигурационное управление» (Вариант №25). На
Этапе 2 реализован разбор аргументов командной строки
и поддержка последовательного исполнения автоматических
стартовых скриптов с выводом отладки.

## 2. Описание функций и настроек
- **Архитектура:** код использует docstring вместо
  строковых комментариев.
- **Основные функции:**
  * `parse_and_expand` — разбиение строк на токены и
    подстановка переменных окружения ОС через знак \$.
  * `print_debug` — логирование параметров запуска.
  * `run_script` — обработка файла конфигурации с
    пропуском некорректных строк команд.
- **Команды:** `exit` (завершение работы), `ls` и
  `cd` (заглушки для вывода переданных аргументов).

## 3. Сборка и запуск
- **Требования:** Python 3.8+, только стандартные
  системные библиотеки.
- **Запуск через управляющий скрипт:**
  ```bash
  chmod +x run.sh && ./run.sh
  ```
- **Прямой запуск эмулятора:**
  ```bash
  python3 src/emulator.py \
    --vfs "/Users/talgat/vfs" \
    --script "start.txt"
  ```
- **Тесты:** `python3 -m unittest discover -s tests`

## 4. Примеры использования
Вывод ошибок аргументов и отладочных логов:
```text
talgat@MacBook-Pro-Talgat.local:~\$ ls \$HOME
[user] Вызвана команда ls
[user] Аргументы ['/Users/talgat']
talgat@MacBook-Pro-Talgat.local:~\$ exit 123
exit: too many arguments
talgat@MacBook-Pro-Talgat.local:~\$ invalid
system: invalid: command not found
```
